# 独立评分与盲评 / v0.2

## Track B：浏览器观察得到的技术分

独立评测不依赖作品提供的 API、PASS 标记或分数。Node 端启动单独的 Playwright 浏览器，在无共享登录状态的新 context 中运行单文件 HTML。

- 800×560 固定 viewport，设备像素比 1。
- iframe 使用 `sandbox="allow-scripts"`，无同源权限，不允许弹窗、表单与下载。
- CSP 禁止网络脚本、图片、样式、字体、连接等；context 阻断请求和 WebSocket，关闭 Service Worker，拒绝下载。数据图片可用。
- 只接受至多 150 KB HTML；同时一个 UI 任务；执行阶段 15 秒超时。浏览器启动耗时在其外。
- 采样四张截图，记录真实观测时间，不声称它们是作品的 0/25/50/75% 周期。
- 记录运行错误、外部资源请求、元素数、可见图形、边界和画面变化比例。

| 检查 | 权重 | 证据 |
|---|---:|---|
| 可见 SVG | 25 | SVG 图形存在，像素不是近似纯底色 |
| 观察到运动 | 25 | 200×140 缩略帧中，至少两个帧对超过 0.05% 像素变化阈值 |
| 几何与画布 | 20 | 未观察到非有限几何，SVG 根画布不超出 viewport |
| 元素预算 | 10 | 每帧 SVG 与后代数量在上限内 |
| 运行与依赖 | 20 | 无脚本/控制台错误、被阻止请求或对话框 |

UI 默认 200 元素；CLI 使用 task.maxElements。所有项通过才 `pass=true`，同时保留连续的 `technicalScore`。孤立圆形的移动也可能得技术满分：这**不等于自行车动作正确**。自动圆形车轮对检测仅作为不计分线索。子图形越过 viewport 的数量仅记录，不直接扣分，因为背景图形常被 SVG 合法裁切。

这是适合本地生成作品的浏览器隔离，不是面向恶意代码的多租户执行服务；没有实现 OS 级 CPU/内存配额。有限采样不能证明整个动画持续正确。不要把它部署成接收互联网上任意 HTML 的公共服务。

阻断 Service Worker 的实现依据：[Playwright BrowserContext](https://playwright.dev/docs/api/class-browsercontext#browser-context-route)。

## 视觉质量：四维人工评分

物种辨识、动作可信、身体结构、视觉完成度四项均为 0–100。全部填写后计算等权平均，结构失败时整体质量门控为 0。没有评审时质量保持 null，技术分不能顶替质量分。

匿名竞技场接受两份 Track A 动物，随机左右顺序，先隐藏标签，在同一相位下显示；完成八项评分才能揭晓。界面隐藏标签是减少评审偏见的手段，不是对有开发者工具访问权的评审保密。演示按钮加载手工精细/极简两版，不是模型基准。

质量/Token 图只显示用户实际录入的总 Token 和四维评审。按实验条件筛选，虚线连接已观测点的 Pareto 前沿，不做插值预测。未知用量不进图。模型/API 标签与用量同样需要外部来源记录支撑。
