# 模型指纹：如何使用，不能证明什么

这是一个**本地作品相似检索实验**，不是型号鉴定器。它没有预装 GPT、Claude 或其他模型的真实风格样本，也没有虚构识别准确率。

## 使用

1. 在“模型指纹”选择当前 SVG/JSON 或上传截图。源码模式只渲染动物，排除公共自行车与背景；图片模式使用上传的整张图，需自行统一裁剪、尺寸和背景。
2. 设置同一实验条件：题目、预算、Skill、格式、元素限制、挑战、采样策略等。不同条件不混算，图片和源码模式也不混算。
3. 分析得到特征后，填写已知模型版本与实际来源说明，把作品登记到本地库。或导入导出的 JSON 样本数组。
4. 每个候选至少三份不同来源回答，且至少两个候选，才进行检索。待测作品本身与重复哈希不作为训练参考。
5. 分析未知作品，查看前三候选、距离、相似度、接近特征和弃权理由。分析与样本均可导出。

来源说明是录入者声明，工具无法认证。改个空格就会改变源文件哈希，因此哈希去重不是语义去重；不要用同一回答的改写凑样本数。

## 方法

源码模式有 10 个结构特征：路径占比、曲线命令占比、圆形占比、分组占比、显式十六进制颜色数量、元素密度、小数占比、脚本占比、CSS/SMIL 动画指示、JS 动画指示。后面两项在 Track A 中通常恒为零。格式化或同义 SVG 写法可能改变部分特征。

另有 4 个粗粒度画面特征：水平对称、相对左上角颜色的非背景占比、RGB 离散度、边缘密度。图像缩放到 96×96、白底等比例填充。源码动物在固定姿态渲染。图片模式只使用这四项，**不会理解图片中的物种或含义**。背景和截图工具可能影响结果。

各特征已缩放至 [0,1]，使用等权欧氏均方根距离。每个模型取最近三个样本距离的均值；显示 `100 × (1 − 距离)` 为相似度，**不是概率**。距离大于 0.30 时认为分布外；前两名间距小于 0.035 时认为无法区分。这些阈值是未校准的工程默认值，不是经过真实模型实验得出的性能保证。

样本库足够后可“留一验证”：每次移除一个不同输出，拿剩余同条件样本检索。至少两个模型、各四份不同样本才可能形成有效折。输出可评数、接受数、覆盖率、接受项准确率与混淆矩阵。它不是独立隐藏测试，也不能证明跨题目泛化。近似答案、同批运行或模板泄漏仍会让成绩偏高。

## 为什么保留“无法判断”

模型可能共享模板、模仿彼此，也可能受到提示词、预算、温度、工具与人工修改的影响。风格相似不能认证后台实际调用的模型。真实模型验证还需要可信 provider 元数据及受控实验。此模块只用来建立和检验候选相似假说。

方法边界参考：[Code Fingerprints: Disentangled Attribution of LLM-Generated Code](https://arxiv.org/abs/2603.04212)、[Can adversarial attacks by large language models be attributed?](https://journals.plos.org/complexsystems/article?id=10.1371/journal.pcsy.0000085)。当前实现是透明的手工特征基线，**没有复现这些论文的训练方法或准确率**。
